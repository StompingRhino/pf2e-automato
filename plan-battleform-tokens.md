# План: токен меняется при боевой форме / полиморфе (токены из FA Nexus)

Статус: только план, код не написан. Дата разведки: 2026-11-20. pf2e 8.6.1 (`systems/pf2e/pf2e.mjs`), FA Nexus 0.6.2. Сеть не вызывалась.

## 0. Итог в трёх строках

- pf2e **размер формы уже меняет** (BattleForm -> CreatureSize -> ширина/высота токена), **картинку не меняет никогда**: ни один из 63 эффектов с BattleForm в паках pf2e не содержит `TokenImage`. Штатный механизм картинки есть — правило `TokenImage` (временный override токена, откат при снятии эффекта делает система).
- У FA Nexus **нет публичного API**; в модуле уже есть `scripts/nexus-tokens.mjs` (подбор файла по имени: скачанные файлы + бесплатный каталог). Его и переиспользуем.
- Решение: модуль подмешивает в эффекты с BattleForm в памяти (как `addPermanent` в `neutralize-rules.mjs`) правило `TokenImage` с файлом из Nexus. Данные мира не пишутся, кроме флага-кэша на эффекте. Нет файла — токен не трогаем.

## 1. Что делает pf2e сам

1. **Размер уже меняется.** `BattleForm.overrides.size` -> на `afterPrepareData` создаётся `CreatureSize` (`pf2e.mjs:42976-42982`, `#r()`) -> `system.traits.size`. `ActorPF2e#applyActiveEffects` на фазе `initial` кладёт в `tokenActiveEffectChanges` `width/height/depth` из `size.tokenDimensions` и `texture.scaleX/Y` (0.8 для малого, иначе 1): `pf2e.mjs:33110-33153`. Применяется к токенам актёра в `TokenDocumentPF2e#applyActiveEffects` (`pf2e.mjs:28308-28312`; для сцен с `rulesBasedVision` — штатно). Это и есть «размер стал tiny» у пользователя. Размер модуль **не трогает** (§1.3).
2. **Картинку BattleForm не меняет.** Схема `BattleFormRuleElement` (`pf2e.mjs:42776-42876`): полей `img`/`tokenImage` нет; `overrides.strikes[].img` — это иконка атаки. В 63 эффектах из паков pf2e `TokenImage` = 0 (скан паков, см. §2). Токены форм в pf2e живут отдельным модулем `pf2e-tokens-bestiaries` (его **нет** в `Data/modules`).
3. **`TokenImage`** (`TokenImageRuleElement`, `pf2e.mjs:45107-45283`):
   - Схема: `value` (путь; допускает `{item|...}`, `resolveInjectedProperties` 45240), `tint`, `alpha`, `scale` (число > 0, пишется в `texture.scaleX/Y`), `ring.subject.{texture,scale}` + `ring.colors/effects` (динамическое кольцо), `animation` {duration, transition, easing, name} (core TextureTransition).
   - Как действует: на `afterPrepareData` при `test()` (предикат, не `ignored`) кладёт изменения `type:"override", phase:"final", priority: this.priority` в `actor.tokenActiveEffectChanges.final` (`45229-45282`). Валидация: `isImageOrVideoPath`, иначе `failValidation("invalid value field")`.
   - Приоритет: фаза `final` идёт после `initial` (размер, scale 1/0.8), поэтому `scale` и `src` правила побеждают значения размера. Несколько `TokenImage` — побеждает больший `priority` (порядок применения по приоритету, обычная логика Foundry).
   - **Откат:** значения живут только в памяти документа токена, пересчитываются при каждой подготовке актёра. Удалили/истёк эффект -> правила нет -> токен возвращается к `_source` (`texture.src`) сам. Ничего в данных токена не пишется.
   - **Связанные и несвязанные токены:** изменения берутся с актёра токена (`this.actor.tokenActiveEffectChanges`, `28310`), у несвязанного это синтетический актёр с дельтой; эффект живёт на нём же — работает одинаково (проверить вживую, §5).
4. `ws.assignDefaultImage` / `isDefaultTokenImage` (`28136-28145`, `3825`) — про токен с картинкой по умолчанию; к форме не относится. Карточка чата берёт `token.texture.src` (`29419`) — сменится вместе с токеном.
5. Откуда у пользователя `modules/pf2e-tokens-bestiaries/tokens/bestial/mammalian/gorilla.webp` (ссылка из задачи): **не из эффекта**. Ни в `packs/_source/effects/spell-effect-animal-form_h68Fr3fht1319txv.json`, ни в pf2e такого пути нет (ChoiceSet даёт 9 UUID дочерних эффектов pf2e `spell-effects`, GrantItem). Источник — анимации PF2e Animations: `Data/modules/pf2e-ru/pf2e-animations/autorec.json:206302` (запись «Форма животного (Обезьяна)», `aefx`, макрос `Compendium.pf2e-jb2a-macros.Macros.Humanoid Form`, аргумент `image`). Таких записей 52 (`grep -c "Humanoid Form"`), 49 путей на `pf2e-tokens-bestiaries`. Макрос (`pf2e-jb2a-macros` 2.20.3, макрос `7nrt0AppNUZDPmYk`) **пишет в токен** `texture.src/scale`, `name`, `ring.enabled=false`, `flags.pf2e.autoscale=false` и кладёт оригинал во флаг `flags.pf2e.originalData`; откат — вызов `off`. Тот же путь был в логе сцен мира rustyspirit (`worlds/rustyspirit/data/scenes/000121.log`) — след уже удалённого тестового токена; живого токена с ним нет (проверено 2026-11-20). Это **конфликтный путь по §3.5** (см. §4.7).
6. pf2e сам ничего не делает с `Pest Form` кроме размера tiny, скоростей и т. д.: подтверждает наблюдение пользователя.

## 3. FA Nexus 0.6.2: как устроено

1. **Откуда токены.** (a) Облачный каталог FA: webhook `https://n8n.forgotten-adventures.net/webhook/foundry-nexus-tokens-update-v2` (`content/nexus-content-service.js:185,214`), кэш индекса — IndexedDB браузера `fa-nexus-cloud-tokens-v2` (`content/content-kind-descriptors.js:5`), **не файл на диске**; (b) локальные папки пользователя (настройка `fa-nexus.tokenFolders`, `tokens/tokens-content-sources-dialog.js:23`); (c) скачанные файлы в папке загрузок: настройка `cloudDownloadDirTokens`, по умолчанию `fa-nexus/tokens` (`content-kind-descriptors.js:13`; в этой установке старый `fa-nexus-tokens`, `storage/download-directory-defaults.js`). Сейчас в `Data/fa-nexus-tokens` — 303 .webp (подкаталоги Adventurers, Adversaries, Creatures/{Aberration,Beast/{Birds,Dinosaurs,Mammals,Reptiles},...}, NPCs): случайный набор пользователя; медведя, обезьяны, акулы, змеи и т. п. там **нет** (есть Wolf, Boar, Cat, Deer, Ox, Cow, Lynx, Fox, Raven, Skunk, Allosaurus, 2 дракона и др.).
2. **Имена файлов:** `Name_A1_Size[_ScaleNNN]_Type_NN.webp` (например `Draft_Horse_A1_Large_Scale200_Beast_01.webp`, `Ancient_Silver_Dragon_Gargantuan_Dragon_36x33_01.webp`). `ScaleNNN` — масштаб картинки в токене (`content/inventory-utils.js:44-82`: `scale = NNN/100`, предел 3; Large -> 2x2, Huge -> 3x3, Gargantuan -> NxM из имени).
3. **Программного API нет.** Всё, что экспортируется: `window.faNexus = { open, enablePremiumDevBridge, disablePremiumDevBridge }` (`nexus-app.js:885-889`); поиска/пути нет. `NexusContentService`, `NexusDownloadManager` — внутренние ES-модули (создаются в `nexus-app.js:279,286`), доступны только динамическим `import()` по пути `modules/fa-nexus/scripts/...`. Это приватный API: нужна привязка к версии (так уже сделано в `scripts/nexus-tokens.mjs`, проверка `compat.EXTERNAL.verified["fa-nexus"]`).
   - **Сломано сейчас:** в `scripts/compat.mjs:95` `verified["fa-nexus"] = "0.5"`, установлено 0.6.2; `verified()` в `nexus-tokens.mjs` сравнивает первые два числа версии -> `0.6 != 0.5` -> `nexusToken`/`nexusArt` молча возвращают `null` (заменa токена у призыва и портреты в окне выбора выключены). Методы, которые зовёт `nexus-tokens.mjs`, в 0.6.2 на месте: `list(kind, opts)` (`nexus-content-service.js:542`), `getFullURL(kind, item, state)` (`:563`), `destroy()` (`:801`), `ensureLocal(kind, item, url, {forceDownload})` (`nexus-download-manager.js:511`). Нужно поднять `verified` до `"0.6"` после живой проверки (это входит в кусок F2).
4. **Бесплатно или премиум.** Free-токены: публичный CDN без авторизации `https://r2-public.forgotten-adventures.net/tokens/free_tokens/<path>` (`content-kind-descriptors.js:7-19,75-89`; `getFullURL`: `tier==='free'` -> публичный URL без `state`, `nexus-content-service.js:572-578`). README: «over 1390 unique topdown tokens free», цветовые варианты и Premium Tokens — Patreon Premium (README:9-24). Premium-ссылки подписаны, требуют OAuth-`state` Patreon (`:580-600`): приватное состояние Nexus, модуль его не берёт (как и сейчас: `tier: "free"` в `fromCatalog`).
5. **Детерминированно и офлайн?** Только для уже лежащих на диске файлов (`FilePicker.browse("data", dir)`, без сети). Каталог требует сети (webhook), синхронизируется самим Nexus; `list()` на пустом кэше вернёт пусто. Скачивание бесплатного файла — сеть (CDN) и запись файла в `Data` (`ensureLocal`, `forceDownload:true`; режим `useDirectCloudUrls` для нас не годится — путь должен быть локальным). Значит: **результат зависит от того, что скачано**; полностью офлайн-детерминированно можно только через заранее скачанный набор (`tools/` — скрипт-список «что скачать» для форм, §4.6).

## 4. Решение

1. **Триггер и место.** Новый `scripts/form-token.mjs` (хук, подбор, окно выбора, флаги), подмешивание — одна строка `addFormToken(rules, opts)` в `wrapRules` (`scripts/builtin/neutralize-rules.mjs`, рядом с `addPermanent`, строки 60-69, 73-85). Обёртка над `game.pf2e.RuleElements.fromOwnedItem` уже стоит.
2. **Данные:** `rules/form-tokens.json` — английские **поисковые ключи** (не UI-тексты, §2): `bySlug` (slug эффекта -> имена по убыванию предпочтения), `byChoice` (slug -> значение выбора -> имена). Нет записи — вывод из slug/выбора (`devil-form-barbazu` -> «Barbazu», `monadic-deva` -> «Monadic Deva»). Затравка зверей/стихий — список из `autorec.json` (bat-giant, eagle, pteranodon, wasp-giant; gorilla; black-bear; bison; wolf; tiger; moose; frog-giant; great-white-shark; sea-snake; шесть динозавров; элементали; ant-giant, stag-beetle, centipede, mantis, scorpion, hunting-spider; phoenix; worm-purple; sea-serpent; 4 слизи; arboreal-regent, flytrap-giant, shambler). Псевдонимы: ape -> [Gorilla, Ape], canine -> [Wolf, Dog], cat -> [Panther, Tiger, Lion, Lynx, Cat], deer -> [Deer, Stag, Elk, Moose], bull -> [Bull, Ox, Cow], dragon-form -> [«<Цвет> Dragon» по `dragonType`, затем общий «Dragon» — только запасной]. Pest Form: список кандидатов [Raven, Cat, Fox, Rat, ...] для окна выбора (п. 6), не автоподбор.
3. **Подбор файла (F2).** `nexusToken(actor)` обобщается в `findToken(names, {download})` -> **`{src, scale}` либо `{reason}`**, где `reason`: `disabled`, `no-nexus` (модуль выключен/не стоит), `unverified` (`verified()` не прошёл), `catalog-empty` (каталог не синхронизирован), `offline` (сбой сети/скачивания), `not-found` (поиск реально прошёл и ничего не нашёл). Порядок: (a) скачанные файлы по **всем** именам списка; (b) нет — бесплатный каталог: `list()` **по каждому имени по очереди, пока нет совпадения** (не только по первому слову первого имени), затем `bestMatch`; (c) скачивание — `ensureLocal(..., {forceDownload:true})` под **одним ключом очереди** `queue("form-token:download:<path>")`: один файл не качается дважды, параллельные заявки ждут первого и берут его результат. Дополнительно: предпочтение файлам из `/Creatures/`, стоп-слова (skeleton, spirit, zombie, ghost: `Dragon_Skeleton` не годится как «Dragon»), `ScaleNNN` -> число.
   - **Премиум: ветки кода нет.** Модуль не читает `patreon_auth_data`/OAuth-`state` и не зовёт `getFullURL` для платных (как и сегодня, `tier:"free"`). Драконов (Premium) один раз скачивает ГМ (Руководитель) через окно FA Nexus как пользователь, в ту же папку скачанного; модуль находит их как обычные локальные файлы по п. 3(a). Общий «Dragon» — запасной.
4. **Запись флага (активный ГМ, один раз; F3).** Хук `createItem` (как `events.mjs:870`, `isActiveGM()`): эффект с правилом `BattleForm` на персонаже -> имена (`namesFor`) -> `findToken`. Флаг `flags.pf2e-automato.formToken`:
   - найден -> `{src, scale}`;
   - `{none:true}` **только** при `reason === "not-found"` (поиск реально прошёл);
   - при `disabled/no-nexus/unverified/catalog-empty/offline` флаг **не пишется** (повторим при следующей загрузке/наложении; причина — в `debug`).
   Проход на `ready` по уже висящим эффектам без флага (случай Pest Form на листе). Запись — активный ГМ через `queue`; игроки получают флаг штатной синхронизацией; ГМ не в сети — токен не меняется (принято).
5. **Применение — штатное (F3).** `addFormToken`: для эффекта с BattleForm и `formToken.src` подмешиваем в память `new TokenImage({key:"TokenImage", value: src, scale, ...}, {parent: item, sourceIndex: null})`. Откат — система (§1.3). Данные токена/актёра не пишутся. Условия:
   - режим `formTokens` включён; у актёра нет собственного `TokenImage` (уступаем);
   - **BattleForm у эффекта может быть несколько: у 16 из 63** (devil/angel/daemon/aberrant/ooze/aerial по 4, elemental/insect по 6, fey 5, devouring-dark 5, demon 4, monstrosity 3, nature-incarnate/cosmic/plant/worm по 2, dragon-form). Невыбранные pf2e помечает `ignored` в `preCreate` (`pf2e.mjs:42878-42890`), вторая форма при уже активной — `ignored` в `beforePrepareData` (`42903-42907`). Поэтому `test()` подмешанного правила вычисляется **в `afterPrepareData`**: действует, только если **хотя бы один BattleForm этого эффекта не `ignored`**. Вариант формы (для имён) — по **действующему** BattleForm и выбору ChoiceSet (`item.flags.pf2e.rulesSelections`), а не по порядку правил. Юнит: `devil-form` + `vordine` -> «Vordine»; все BattleForm ignored -> правила нет.
   - **Кольцо:** смотрим токен (`token.ring.enabled`), не только `prototypeToken`. Если `ring.subject.texture` пуст — `ring` **не трогаем** (кольцо берёт `texture.src`). Если задан — ограничение: подмена возможна через `TokenImage.ring.subject` (`pf2e.mjs:45131-45151`), но коррекция масштаба кольца (`scale` >= 0.8) подбирается вручную; в первой версии ставим тот же файл и `scale:1`, проверка вживую (§5).
6. **Pest Form — выбор через окно (F3).** Кандидатов собирает ГМ: локальные файлы по именам списка + превью бесплатного каталога (`getThumbnailURL`, `nexus-content-service.js:550`, без скачивания). Окно показывает **только картинки** (подпись — имя файла FA как есть; заголовок и кнопки — по-русски из `lang`, §2.3). Открывается через `askOwner(actor, "formToken", packed, local)` (`builtin/lib.mjs:152`): владелец-игрок онлайн -> у него, иначе у ГМа; тайм-аут 180 с. Нужна регистрация `formToken` в реестре `runPlayerBuiltin` (`builtin/index.mjs`). **Ожидание не блокирует общую очередь:** окно спрашивается вне `queue` (в очереди только быстрые записи флагов); на актёре в памяти маркер «спрашиваем», чтобы не открыть второе окно. Скачивание выбранного файла — ГМ после ответа (п. 3(c)).
   - Результат — флаг актёра `flags.pf2e-automato.formChoice.<slug эффекта>` = `{name, src, scale}`; он же признак «спрашивали». **Отказ/закрытие/тайм-аут:** пишем `{declined:true}` и больше не спрашиваем (не при каждой перезагрузке); токен не меняется.
   - **Повторный выбор (изменено 2026-11-20 по ходу живой проверки):** по правилам существо выбирается при каждом сотворении — окно появляется при каждом новом эффекте Pest Form (createItem), прошлый выбор отмечен по умолчанию; проход по висящим эффектам на `ready` не спрашивает, если выбор уже был. Alt-сброс убран. Отказ/закрытие — токен как есть до следующего превращения.
7. **Совместимость (§3.5) и отключение PF2e Animations (F4, разовая операция ГМа).** Токен форм — `TokenImage` в `final`; запись «Humanoid Form» из autorec пишет `texture.src` в источник токена и возвращает при `off`. Два источника правды плюс ссылки на отсутствующий `pf2e-tokens-bestiaries` -> **выключаем макрос в записях**, анимация остаётся:
   - Источник: мировая настройка AA `autoanimations.aaAutorec-aefx` (записи меню `aefx`). Отбор **только по `macro.name`**, оканчивающемуся на `Humanoid Form` (52 записи по `grep` в `autorec.json`; прочие записи не трогаем).
   - Действие: `macro.enable = false` у отобранных (остальные поля и анимация — как есть).
   - **Иначе «Update» вернёт:** `pf2e-jb2a-macros` при обновлении автореки сравнивает записи с модульными и возвращает их (`module/updateMenu.js:38-62`), пропуская те, чьи метки лежат в `game.settings.get("pf2e-jb2a-macros","blacklist").entries` (`module/settings.js:146-152`). Метки (`label`) отобранных записей **добавляем** в `blacklist.entries` (объединение множеств, без дублей).
   - **Перед правкой — резервная копия:** экспорт текущего значения `aaAutorec-aefx` (JSON) в файл с датой в `Data/` рядом с миром и копия в scratchpad; откат — `settings.set` исходного значения и удаление добавленных меток из `blacklist.entries`.

   - Token Magic / Auto Animations: фильтры висят на меше и `texture.src` не трогают. `TokenImage.animation` по умолчанию не включаем.
   - Двойной эффект: ручных путей смены токена у форм в модуле нет; `summon.mjs:nexusSwap` форм не касается.
8. **Настройка.** Мировая булева **`formTokens`** (по умолчанию включена; включает и скачивание бесплатных токенов для форм), регистрируется в `form-token.mjs:init`. **Призыв (`nexusTokens`) не трогаем.** `onChange`: пересборка актёров с формами **включая актёров несвязанных токенов** (образец — `resetActors`, `neutralize-rules.mjs:117-121`: `game.actors` + `scene.tokens` без `actorLink`, `a.reset()`). Строки — `lang/{ru,en}`.
9. **Размер** — не трогаем (§1.1). `scale` из имени файла (`Scale130` -> 1.3) идёт в `TokenImage.scale` (поверх 1/0.8 от размера). **Запасной вариант** (нет Nexus, файл не найден, настройка выкл., `{none}`, `declined`): правило не подмешивается, токен как есть; причина — в `debug`; пользователю — ничего. `tools/form-tokens.mjs` печатает «что скачать» (имена без найденного файла).
10. **Отключаемость и обратимость:** без модуля или при `formTokens=false` обёртка не подмешивает — поведение pf2e (размер есть, картинки нет). След в данных — флаги `formToken` (на эффекте, уходит с ним) и `formChoice` (на актёре).
